Operadores lógicos: $and
and -> todos os critérios precisam ser verdadeiros

or -> Pelo menos um dos critérios deve ser verdadeiro

nor -> Nenhum dos critérios deve ser verdadeiro

RESULTADO DE BUSCA COM and
loja> db.produtos.find( { $and: [ { categoria:"eletronicos" }, {preco:{$gt:100} }] })
[
  {
    _id: ObjectId('6a32e2d66e54e3bec7abc115'),

    _id: ObjectId('6a32e2d66e54e3bec7abc116'),
    nome: 'iphone',

  }
]

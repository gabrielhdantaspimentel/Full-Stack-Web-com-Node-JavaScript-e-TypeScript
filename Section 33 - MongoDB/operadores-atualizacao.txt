OPERADOR DE inc PARA INCREMENTAR (pra decrementar é só colocar -1 ou o valor que tu quer tirar)

INCREMETANDO 1 REAL 
loja> db.produtos.updateOne( {nome:"quadro"}, {$inc:{preco:1} } )
{
  acknowledged: true,
  insertedId: null,
  matchedCount: 1,
  modifiedCount: 1,
  upsertedCount: 0
}

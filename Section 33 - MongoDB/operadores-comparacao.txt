FAZENDO BUSCA COM OPERADORES LÓGICOS ***
$gt 
$ = operador lógico
gt = greater than

loja> db.produtos.find( {preco: {$gt:100}}, {nome:true, preco: true, _id:false} )

RESULTADO DA BUSCA ABAIXO ***
[
  { nome: 'notebook', preco: 1200.9 },
  { nome: 'iphone', preco: 4900 }
]

lt = less than
loja> db.produtos.find( {preco: {$lt:100}}, {nome:true, preco: true, _id:false} )
[ { nome: 'jaqueta', preco: 89.9 }, { nome: '1984', preco: 64.9 } ]


lte = less than equal = menor ou igual a

loja> db.produtos.find( {preco: {$lte:100}}, {nome:true, preco: true, _id:false} )
[
  { nome: 'jaqueta', preco: 89.9 },
  { nome: 'quadro', preco: 100 },
  { nome: '1984', preco: 64.9 }
]


ESSE e DA PRA USAR TANTO NO gt QUANTO NO lt

ne = NOT EQUAL

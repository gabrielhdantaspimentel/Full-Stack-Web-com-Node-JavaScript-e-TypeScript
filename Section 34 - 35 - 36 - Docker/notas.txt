Introdução as Images e ao Docker Hub


Imagem - é um requisito para que seja possível, a partir da imagem, executar algo de fato. Ela guarda tudo o que é necessário para que, quando seja executada, ela atenda ao seu objetivo.


Images são sempre baixadas do Docker Hub



O Docker Hub é uma biblioteca na nuvem (um repositório público e privado) onde ficam armazenadas as imagens de containers prontas para uso.

Em resumo: ele funciona como a App Store ou o GitHub do Docker, onde você pode baixar imagens oficiais (como Node.js, Ubuntu ou MySQL) ou subir as suas próprias imagens para compartilhar com outras pessoas.



Images são baixadas no ambiente (Docker Host)
